## Passo 1 (cont.) — Consequências estudadas na documentação oficial (docs.whmcs.com 9.1)
- *Payment Gateways → Show on Order Form*: controla a exibição no formulário de pedido **e na Área do Cliente** (respeitando restrições de gateway do grupo de produtos).
  Com a opção desligada o `iugucc` fica oculto para clientes; o Admin ainda pode atribuí-lo a uma fatura específica (teste de fumaça na `#21381`).
- *Payment Gateways → Deactivating*: desativar reatribui faturas, serviços, transações e meios de pagamento ao gateway escolhido — rollback seguro do `iugucc`.
- *Payment Gateways → Third-party*: "Attempt Capture" fica desativado; o pagamento só ocorre quando o cliente paga na fatura.
- *Promotions*: tipo **Price Override** = R$ 5,00, **sem Recurring** (só a 1ª fatura), Applies To = Imóvel Site (pid 177), Maximum Uses = 1,
  New Signups + Apply Once, validade até 13/11/2026 (inclusiva até 23:59:59). Código não divulgado. Pode ser expirado na hora com "Expire Now".
